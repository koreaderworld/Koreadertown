# Koreaderworld — 음성 채팅 서버판

claude.ai 안에서는 마이크와 카메라를 쓸 수 없어서, 접속자끼리 **음성·화상으로 대화**할 수 있도록 직접 운영하는 서버 버전이에요.
게임 내용(공원 마을, 가게, 카페, 우리 집, 마트 장보기, 퀘스트 등)은 claude.ai 버전과 같고, 여기에 근접 음성 채팅이 더해졌어요.

## 들어 있는 것
| 파일 | 역할 |
|---|---|
| `server.js` | 서버 하나로 전부 처리해요. 설치할 패키지가 없어요 (Node.js 18 이상) |
| `public/index.html` | 게임 |
| `public/shim.js` | 게임을 이 서버에 연결해 주는 부분 |

서버가 하는 일
- 접속자 위치·채팅·이모트를 실시간으로 전달 (WebSocket `/ws`)
- 음성 연결 정보 중계 — **목소리 자체는 서버를 거치지 않고 브라우저끼리 직접(WebRTC)** 오가요
- 직원 자유 대화·한국어 교정·번역을 Claude에게 전달 (`/api/claude`, API 키는 서버에만 보관)
- 랭킹 저장 (`data/scores.json`)

## 음성 채팅 사용법
1. 오른쪽 위 **🎙 음성 채팅** 버튼 → 브라우저가 마이크 권한을 물으면 **허용**
2. 공원에서는 **가까울수록 크게**, 3m 안이면 또렷하게, 24m 넘으면 안 들려요. 왼쪽·오른쪽 방향도 느껴져요
3. **같은 가게 안**에 있는 사람끼리는 거리와 상관없이 잘 들리고, 가게 밖과는 서로 안 들려요. 우리 집은 각자의 집이라 아무도 안 들어와요
4. 말하는 사람 머리 위에 🔊 표시가 떠요
5. **🎤 마이크 켜짐** 버튼이나 키보드 **M**으로 음소거

## 교실 화상 채팅
1. **한글학교** 교실에 들어가면 오른쪽 위에 **📹 영상 채팅** 버튼이 생겨요
2. 누르면 카메라(와 마이크) 권한을 물어요 → **허용**. 음성 채팅이 꺼져 있었다면 같이 켜져요
3. 교실 안에서 카메라를 켠 사람들의 얼굴이 화면 위쪽(휴대폰은 아래쪽)에 칸으로 나란히 떠요. 내 화면은 노란 테두리예요
4. 교실을 나가면 카메라는 자동으로 꺼지고, 영상은 교실 안 사람에게만 보내져요
5. 영상은 320×240, 초당 15장 정도로 가볍게 보내요. 한 교실에 **4~6명**이 함께 영상을 켜는 정도가 쾌적해요

## 내 컴퓨터에서 먼저 실행해 보기
```bash
node server.js
# 브라우저에서 http://localhost:3000
```
`localhost`에서는 http여도 마이크가 돼요. Claude 기능을 쓰려면:
```bash
ANTHROPIC_API_KEY=sk-ant-... node server.js
```
(Windows PowerShell: `$env:ANTHROPIC_API_KEY="sk-ant-..."; node server.js`)

## 인터넷에 올리기 (Render 무료 플랜 예시)
1. 이 폴더를 GitHub 저장소에 올려요 (`.gitignore`가 `data/`와 `.env`를 빼 줘요)
2. [render.com](https://render.com) → **New → Web Service** → 저장소 선택
3. 설정
   - Runtime: **Node**
   - Build Command: 비워 두기 (또는 `echo ok`)
   - Start Command: `node server.js`
4. **Environment**에 `ANTHROPIC_API_KEY` 추가 (Anthropic Console에서 발급)
5. 배포가 끝나면 `https://○○○.onrender.com` 주소가 생겨요 → 친구들에게 이 주소를 공유

Railway, Fly.io, 개인 VPS도 같아요: `node server.js`를 실행하고 HTTPS 주소로 접속하면 돼요.
**마이크와 카메라는 https 주소에서만 켜져요** (localhost 제외). 개인 서버라면 Nginx/Caddy로 HTTPS를 붙여 주세요.

## 환경 변수
| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 호스팅이 자동으로 정해 주면 그대로 둬요 |
| `ANTHROPIC_API_KEY` | (없음) | 없으면 직원은 미리 준비된 대답만 해요 |
| `CLAUDE_MODEL` | `claude-haiku-5-5` | 직원 대화에 쓸 모델 |
| `MAX_PLAYERS` | 30 | 동시 접속 최대 인원 |
| `TURN_URL`, `TURN_USER`, `TURN_PASS` | (없음) | 아래 "연결이 안 될 때" 참고 |

## 알아 두면 좋은 점
- **인원**: 음성은 사람끼리 직접 잇는 방식이라, 음성 채팅을 켠 사람이 **한 번에 8명 정도**까지가 쾌적해요. 접속(보기·채팅)은 `MAX_PLAYERS`까지 가능해요.
- **연결이 안 될 때**: 회사·학교 와이파이나 일부 모바일 데이터는 브라우저끼리 직접 연결을 막아요. 이럴 땐 TURN 서버(예: metered.ca 무료 플랜, 또는 coturn 직접 설치)를 만들고 `TURN_URL=turn:주소:3478`, `TURN_USER`, `TURN_PASS`를 넣어 주세요.
- **Render 무료 플랜**: 15분 동안 아무도 없으면 잠들고, 다음 접속 때 30초쯤 걸려 깨어나요. 디스크가 배포 때마다 초기화돼서 **랭킹이 사라질 수 있어요** (유료 Persistent Disk를 `data/`에 연결하면 유지돼요).
- **비용**: Claude 대화는 Anthropic API 사용량만큼 요금이 나와요. 서버가 접속자 한 명당 분당 30회로 제한해요.
- **저장**: 엽전·옷·가방·집 상태는 각자의 브라우저에 저장돼요. 브라우저나 기기를 바꾸면 처음부터예요.
- **보안**: API 키는 서버 환경 변수에만 두고, `public/` 파일이나 GitHub에 넣지 마세요.
